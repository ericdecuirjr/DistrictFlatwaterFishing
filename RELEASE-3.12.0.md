# District Flatwater Fishing 3.12.0

Saved spots: open Map → Saved spots & kayak launches, or More → Saved fishing spots. Create, edit, search or delete places without logging a catch. Record the waterbody, Want to try/Fished status, access notes, kayak launch notes and optional coordinates. GPS can be entered manually or explicitly captured at the spot. Saved places with coordinates appear as stars on the existing map, independently of catch filters. Deleting a spot never changes catches or trips.

Spots are included in backups and restored in the same transaction as catches and trips. Older backups remain supported. Storage upgrades add a spots store without rewriting catches, photos or trips.

Measurement: a 4× endpoint detail view shows a crosshair at the selected point. Onscreen arrows move that endpoint by one original photo pixel. Existing fit, zoom, pan, saved points and manual overrides remain available. Reference guidance explains card edges, coin diameter and perspective limitations. Estimates remain approximate.

Phone check: export a backup, install the signed update over the existing app, verify existing catches/trips, save a place and check its star on Map, edit/reopen it, then measure a photo and refine an endpoint with the arrows.
