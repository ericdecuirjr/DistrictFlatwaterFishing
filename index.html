PREFERENCES

Settings & backup

Gemini fish identification

AI identification requires a secure companion service. Set its HTTPS URL below after deployment. Do not enter an API key here.

The Gemini API key belongs in a server-side secret, never in app files or GitHub Pages.

Your catch data

Your pictures and catch details are saved locally on this browser/app installation. Export backups regularly, especially before changing phones or installing a separate Android APK.

Import adds catches and updates matches by ID; it does not erase other catches.

How weather is recorded

Temperature, local surface pressure and conditions come from Open-Meteo forecasts/models. These values are estimates for the logged location and time, not direct ambient sensor readings. If you're offline, the catch saves without them.
